# iQMS Landing Page

Animated landing page for **iQMS Mini + Customization**.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The landing page uses React, Vite, Framer Motion and Lucide icons. Motion respects `prefers-reduced-motion`.

## Before launch

- Replace `hello@iqms.example` with the production sales/contact channel.
- Replace or expand copy as the final iQMS Mini scope is confirmed.
- Connect CTA buttons to the actual demo / booking flow.
